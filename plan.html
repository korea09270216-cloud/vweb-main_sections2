03 — 01

V REPORT. 홈페이지와 함께 드리는 리포트

목적
홈페이지를 넘길 때 함께 전달하는 AI 가시성 리포트를 "고객이 받게 되는 결과물"로 보여주고, 무엇이 담기는지 쉬운 말로 이해시킨다. (요청: 전달 시 함께 제공하는 AI 가시성 리포트 어필)
카피
홈페이지를 드릴 때, 리포트도 함께 드립니다.어려운 말은 빼고, 작업한 내용만 쉽게.AI가 읽기 쉽게 어떤 작업을 했는지, 쉬운 말로 정리해 드려요.
구성
  1. 전달 순서 3단계 — 홈페이지 제작 → 작업 내용 정리 → 함께 전달 (「기본 제공」 배지)
  2. 리포트 4쪽 목업 — 표지 · 01 AI가 읽기 쉽게 · 02 AI가 답으로 쓰기 쉽게 · 03 이런 효과를 기대합니다. 각 쪽은 핵심만(항목 이름 + 큰 숫자 한 줄) 보여 주고 자세한 내용은 호버 → 미리보기의 실제 리포트로 + 칩 4 (PDF 파일 · 표지 포함 4쪽 안팎 · 어려운 용어 없이 · 추가 비용 없이 기본 제공)
  3. 미리보기 — PC는 4쪽 아래 안내 문구("리포트 위에 마우스를 올리면…")와 함께, 4쪽 위에 마우스를 올리면 흐려지면서 「미리보기」 버튼이 뜨고, 터치 · 모바일은 버튼이 항상 보임. 누르면 팝업에서 실제 리포트(딩딩파파, 4쪽)를 내려받기 없이 화면에서 열람(PDF.js, 처음 열 때만 불러옴) + 「새 탭에서 열기」
  4. 담기는 내용 카드 4 — 글의 뼈대 · 그림 설명 · 질문과 답 · 근거 숫자
  5. 마무리 문구 + 면책 문구
모션
PC 4쪽이 아래에서 차례로 올라오고(스태거) → 목업 속 숫자 카운트업(제목 · 이미지 · 질문 수) → 체크 마크 장식. 각 블록은 자기 트리거. 호버하면 4쪽이 블러 처리(0.45초)되고 미리보기 버튼이 떠오름.
모바일 페이지를 옆으로 넘기는 스냅 스트립 + 넘김 점. 카운트업은 생략(옆으로 넘겨야 보이는 쪽이라 화면 밖에서 끝나 버림), 카드는 항목마다 개별 트리거.
근거 기능
  • 시맨틱 마크업 설계: 머리말 · 메뉴 · 제목 · 본문
  • 이미지 대체 텍스트(alt) 설계
  • 질문과 답 구조(FAQ)
  • 인용 근거가 되는 숫자를 글자로 표기
  • 기대 효과 · 면책 문구가 들어간 PDF 리포트를 제작해 전달
표현 주의
리포트는 프로젝트마다 제작해 전달하는 산출물이라 "홈페이지와 함께 전달"로 표현 (자동 생성 도구처럼 쓰지 않음). 노출 순위 · AI 인용은 보장할 수 없으므로 "가능성이 높아집니다 · 더 잘 찾아집니다" 수준으로 쓰고, 4쪽 목업(한 줄 문구)과 하단에 면책 문구를 넣음. 리포트 속 수치와 브랜드(모노브루)는 모두 가상 예시이며 「예시」로 표기. JSON-LD · 사이트맵은 이 섹션에서 다루지 않음. 미리보기의 PDF는 딩딩파파 홈페이지의 실제 리포트라 공개 레포에 함께 올라가며, 가상 예시(모노브루)와 구분되도록 버튼 · 팝업에 「딩딩파파 실제 리포트」로 표기. 다른 고객사 리포트로 바꾸려면 pdf/ 폴더의 파일만 교체.

03 — 02

V WRITE. AI 문구 추천

목적
수정모드에 붙는 AI 문구 추천이 무엇이고 어떻게 쓰는지 실제 화면 그대로 시연으로 이해시키고, 직접 수정은 일정 단계 이상 · AI 문구 추천은 사용량 비용이 드는 선택 옵션이라는 이용 구조를 투명하게 안내한다. (요청: 직접 수정은 다른 섹션에서 다루므로 여기서는 문구 추천 중심)
카피
문구가 막막할 땐, AI에게 물어보세요.제안은 AI가 하고, 결정은 사장님이.글자를 드래그하고 AI 버튼만 누르면, 추천 문구 3개가 나옵니다.
구성
  1. 브라우저 창 목업 — 「수정모드 ON」, 점선 편집 영역, 툴바 맨 왼쪽 AI 버튼, 위로 열리는 3가지 메뉴(더 짧게 · 검색 잘 되게 · 다른 추천 문구), 추천 3개 + 「적용」, 「저장 (1)」
  2. 눌러서 직접 보는 기능 버튼 3 + 안심 포인트 3 (추천 3개 중에서 고르기 · 적용 전에는 그대로 · 수정모드에서 관리자만)
  3. 이용 안내 계단 3단 — 호스팅 기본 단계 → 수정모드 제공 단계 이상(직접 수정) → 선택 옵션(AI 문구 추천) + 비용 안내 문구
  4. 마무리 문구
모션
창이 화면에 들어오면 1회 자동 재생(약 12초): 커서가 문구를 드래그 → 툴바가 올라옴 → AI 클릭 → 메뉴 → 선택 → 로딩 → 추천 3개 → 하나를 골라 적용 → 글자만 바뀜 → 저장 (1). 아래 기능 버튼 3개를 누르면 그 기능으로 다시 재생. 계단 카드는 낮은 단계부터 차례로 올라옴. 핀 없음(진입 시 재생).
근거 기능
  • 수정모드 툴바 맨 왼쪽 AI 버튼
  • 위쪽으로 열리는 메뉴 3종
  • 추천 3개 → 고른 것으로 선택한 글자만 교체
  • 기존 「저장 (N)」으로 반영
  • 관리자 전용
  • 사용 한도 설정
  • 사용량 기반 AI 호출
표현 주의
AI 사용량에 따라 비용이 발생하므로 "무료 · 기본 제공"으로 쓰지 않고 "선택 옵션 · 사용량에 따라 비용 발생 · 신청 시 안내"로 표기. 직접 수정은 일정 단계 이상 호스팅 고객 대상이라 계단 구조로 안내. 호스팅 단계 이름 · 요금 방식은 미확정이라 일반 표현으로 두었음(확정되면 문구만 교체). AI 모델명 · 업체명 · 사용 한도 수치는 공개하지 않음. AI 문구는 참고용이라 "사실과 맞는지 확인 후 적용" 문구를 포함. 수정 이력 · 되돌리기는 제공하지 않으므로 카피에서 사용하지 않음. 예시 문구는 원문에 있는 사실만 다시 표현한 가상 예시.
